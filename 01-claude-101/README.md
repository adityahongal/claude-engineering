## What the course covers

- What Claude is: an AI assistant (a large language model) that understands and
  generates natural language.
- How to interact with Claude: prompts in, responses out.
- Core concepts: what a "prompt" is, giving context, being specific.
- Where Claude can be used (chat, and later — via API — inside apps).

## Key takeaways (from a frontend POV)

- **A prompt is like props.** What you pass in shapes what you get back — garbage in,
  garbage UI. Being specific matters just as much here as with component props.
- **Context is state management.** The AI only "knows" what you give it in the moment.
  Give it the right context and the output stays consistent; leave it vague and it guesses.
- **The AI can't read minds.** You have to spell out what you want — format, tone, goal.
  Feels a lot like debugging CSS: the fix is usually "I didn't say exactly what I meant."
- **Prompt engineering is a real skill**, not a buzzword — it's the difference between an
  okay answer and a genuinely useful one.

## New terms I learned

- **Prompt** — the instruction/message you give the AI.
- **Context** — the background info you give it so the answer fits your need.
- **LLM (Large Language Model)** — the type of AI Claude is; trained on huge text data.
