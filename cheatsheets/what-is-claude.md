# What is Claude? — Cheatsheet

**What it is:** Claude is an AI assistant built by Anthropic. It's a *Large Language
Model (LLM)* — trained on huge amounts of text so it can understand and generate
natural language.

**How you use it:**
1. You give a **prompt** (an instruction or question).
2. Claude reads it along with any **context** you provide.
3. It **generates** a relevant response.

**Key terms:**
- **Prompt** — what you ask/tell the AI.
- **Context** — background info you include so the answer fits your need.
- **LLM** — the kind of AI Claude is (learns patterns from lots of text).
- **Token** — a chunk of text (roughly a word-piece) the model reads/writes in.

**Good prompting basics:**
- Be specific about what you want.
- Give context (who it's for, format, constraints).
- Show an example if you can.

**Why it matters:** This is the foundation. Everything else — RAG, tool use, agents —
is just smarter ways of giving Claude the right prompt + context.
